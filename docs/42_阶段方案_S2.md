## 1. 背景

S1 已验收：IMU 姿态 200 Hz（实测 `0x41` 199.78 帧/s，跨断电保持）、CRC 全 0、`age 6 ms`；FOC 内环 300~2000 rpm 实测正常。

但固件里**没有任何姿态抽象**。`imu_get_ahrs()` 直接返回模块的 roll/pitch/heading：单位是度、坐标系是模块自己的、
零位是模块上次校准的水平面。而平衡律需要的是"本体俯仰角 θ / 角速度 θ̇ / 轮速 ω"，与这三者都不同：

| 差异 | 现状 | S2 要解决 |
|---|---|---|
| 坐标系 | 模块自己定义 | 用常值旋转 `R_body←sensor` 换到本体轴 |
| 零位 | 模块上次校准的水平 | 编译期常量 + 运行时 `att zero` |
| 语义 | 模块内部融合的欧拉角 | 本体倾角，带有效性与量程判定 |
| 质量 | 未知 | 实测漂移、噪声、帧龄、动态误差 |

S1 证明"链路通"，S2 证明"数能用"——两者的验收方式不同（`workflow/03`：能做 ≠ 做得对）。

## 4. 技术路线

### 4.1 备选方案

| 方案 | 做法 | 优点 | 缺点 | 结论 |
|---|---|---|---|---|
| A | 透传模块 `0x41` 的 pitch/pitch_speed，做常值旋转、零位、单位与有效性处理 | 代码最少、不引入额外延迟、可立即量化模块质量 | 依赖模块内部融合，动态误差不可控 | **选定** |
| B | 用 `0x40` 的陀螺 + 加速度计在固件侧做互补滤波 | 延迟与带宽可控 | 需标定加速度计与安装矩阵，工作量翻倍；`0x40` 还要提到 200 Hz | 方案 A 不达标时的后备 |
| C | 固件侧卡尔曼（陀螺 + 加速度计 + 编码器） | 理论最优 | 参数与验证成本最高，S2 阶段不划算 | 不采用 |

### 4.2 关键决定

1. **量测来源**：θ 取 `0x41.pitch`，θ̇ 取 `0x41.pitch_speed`，ω 取 `mid_enc`。**不差分、不积分**。
2. **刚性连接的结论**：IMU 与立方体刚接 → **角速度、角加速度、姿态与立方体通用**；线加速度不通用，S2 不用它。
3. **坐标约定（本阶段固化，后续不许改）**：
   - 本体轴：+X 指向立方体前面，+Y 指向左侧，+Z 指向上方。
   - θ 绕 **Y 轴**旋转，`θ > 0` 表示**向前倒**（沿 +X 方向倾覆）。
   - 安装关系用宏表达（见 4.3），不改公式。默认假设：模块 PCB 与立方体前面平行、丝印 Y 轴朝前；实物核实项见 `18#T6`。
4. **零位**：`att zero` 把当前 θ 记为 0，只改 RAM 变量（**不写 flash**，避免误擦校准页）；上电默认用编译期常量。
5. **滤波默认关闭**：`ATT_LP_HZ = 0` 表示不滤波。先测原始噪声与动态误差，S4 再决定是否开一阶低通。
6. **有效性由调用方给**：`mid_att` 不自己算帧龄，调用方传入 `age_ms`；`age_ms > ATT_TIMEOUT_MS` 时 `valid = 0`。
7. **量程**：模块 pitch 为 −90°~+90°；`mid_att` 限幅到 ±60°，越界置 `valid = 0`（平衡工作域只有 ±3°）。
8. **不新增中断**：`mid_att` 在 `app_loop()` 里与 `imu_poll()` 同拍更新，200 Hz 零阶保持不变。

### 4.3 配置宏（`User/Cfg/board_cfg.h`）

| 宏 | 默认值 | 含义 |
|---|---|---|
| `ATT_AXIS` | `ATT_AXIS_PITCH` | 使用模块 pitch 轴；预留 `ATT_AXIS_ROLL` 供安装面变化 |
| `ATT_SIGN` | `1` | 方向标定，实物核实后改 ±1 |
| `ATT_OFFSET_DEG` | `0.0f` | 编译期零位；`att zero` 只改 RAM |
| `ATT_LP_HZ` | `0.0f` | 0 = 不滤波 |
| `ATT_TIMEOUT_MS` | `100u` | 超过即判无效 |
| `ATT_RANGE_DEG` | `60.0f` | 有效范围上限 |

### 5.1 接口草案（评审后定稿）

```c
typedef struct {
    float    theta_deg;      /* body pitch, + = lean forward */
    float    theta_dot_dps;  /* body pitch rate */
    float    wheel_rpm;      /* from mid_enc */
    uint16_t age_ms;         /* age of the source frame */
    uint8_t  valid;          /* 1 = usable by the balance law */
    uint32_t seq;
} att_state_t;

void  att_init(void);
void  att_update(const fdilink_ahrs_t *ahrs, uint16_t age_ms, float wheel_rpm);
const att_state_t *att_get(void);
void  att_zero(void);
float att_offset_deg(void);
```

### 5.2 L1 用例清单

| # | 用例 | 断言 |
|---|---|---|
| 1 | 零位为 0 时直通 | `theta == pitch` |
| 2 | 设偏移后减去偏移 | `theta == pitch - offset` |
| 3 | `ATT_SIGN = -1` 时取反 | 符号翻转 |
| 4 | 角速度同符号透传 | `theta_dot == pitch_speed` |
| 5 | 限幅：pitch = 89° | `theta == 60` 且 `valid == 0` |
| 6 | 限幅边界：pitch = 60° | `valid == 1` |
| 7 | 超时：age = 150 ms | `valid == 0` |
| 8 | 超时边界：age = 100 ms | `valid == 1` |
| 9 | 低通开启后阶跃收敛 | 3 个时间常数后误差 < 5% |
| 10 | 低通关闭时无相位滞后 | 单拍直通 |
| 11 | `att_zero` 后 θ 归零 | `fabs(theta) < 1e-6` |
| 12 | 连续喂帧 seq 单调 | `seq` 递增 |

实施中改变了两处设计（都已写注在源码里）：

1. **单位**：`mid_fdilink.h` 里的 `fdilink_ahrs_t` 存的是 **rad / rad/s**（本方案草案写的“度”是错的），
   所以 `mid_att` 负责 rad→deg，对外只说度；控制律、控制台、文档统一用度。
2. **边界**：恰好落在 `±range` 上的读数，经过一次 deg→rad→deg 的单精度往返会偏出
   几个 1e-6 度，从而被误判为越界；新增 `ATT_RANGE_EPS_DEG`（0.01°）作为守护带，
   边界读数保持可用，超出守护带才置 `valid = 0`。L1 第 6 例就是为此存在的。
3. **重复帧不推进滤波器**：`mid_att` 用 `ahrs.timestamp_us` 算采样间隔，同一时间戳视为
   "没有新信息"并保持当前值。主循环约 156 kHz，若重复帧也按"跳变到目标"处理，低通会被击穿。
   L2 注入帧必须带递增时间戳（`att_feed()` 每帧 +5000 µs），否则测到的是"保持"而不是"跟踪"。
4. **`log_printf` 不支持 `+` 标志**：`mid_log` 只解析 `-`/`0`/宽度/精度，`%+.2f` 会被当成未知
   转换、把数值吞掉；`print_att()` 改为显式符号串 + `fabsf()`。顺手修掉 `print_imu()` 的
   单位 bug（`fdilink` 存的是 rad，原来直接按度打印，差 57 倍）。

## 5.4 工作点实测与配置定案（2026-11-04）

| 项 | 值 | 依据 |
|---|---|---|
| 控制轴 | `ATT_AXIS = ATT_AXIS_ROLL` | 棱平衡时 pitch 残差仅 0.47°，棱平行于 Y 轴（`19` §6.1） |
| 零点粗基准 | `ATT_OFFSET_DEG = 46.0f` | 手扶棱位 46.23° − 安装偏置（−0.12°）= 46.35°，取 46.0 |
| 零点精调 | 现场 `att zero` | 手不是平衡点（用户指出），真实值由质心决定 |
| 残余静差 | 控制律慢速偏置积分 | 捕获窗口 ±2.9°，1° 误差吃掉三分之一（`18#T20`） |
| 符号 | `ATT_SIGN = +1`（未定） | S3 轮反作用试验定，手扶法判据模糊（`18#T19`） |
| 量程 | `ATT_RANGE_DEG = 60`（保留） | 只作"读数是否可信"的合理性上限；安全工作区另由 S5/S6 的 ±20° 停机判据管 |

设计含义（写进 S6 的启动条件）：**立方体沿 X 轴正负两侧都可能倒**，所以控制律与启动判据都必须对称；
手扶摆位 sd 0.75°，启动门限取 `|θ| < 1.0°` 才能既摆得进去、又不会在半倒的状态下接管。

## 7. 风险与对策

| 编号 | 风险 | 概率 | 影响 | 对策 |
|---|---|---|---|---|
| R1 | 安装轴与默认假设不同（`18#T6`） | 中 | 符号或轴全错，S4 白做 | `ATT_AXIS`/`ATT_SIGN` 用宏切换；上板第一步做翻转核对，不通过就换宏，不改公式 |
| R2 | 模块动态姿态误差大（`α×r` 混入） | 中 | 平衡环可用增益下降 | S2 量化后写入 `90#L-6`；若滞后 > 10 ms，S4 前改走方案 B |
| R3 | pitch 越过 ±90° 回绕 | 低 | 单拍角度跳变 180° | 限幅 ±60° + 越界置 `valid = 0`；S6 的倾角保护另做 |
| R4 | 长时运行零位慢漂移 | 中 | 静差增大 | 记录 10 min 漂移率；S6 前加"直立时慢积分归零" |
| R5 | `att` 命令刷屏打乱 200 Hz 节奏 | 低 | 帧龄出现尖峰 | 命令输出限 20 Hz；用 `prof` 观测 `imu` 与 `att` 耗时 |

## 8. 回退方案

- `mid_att` 是**只读旁路**：去掉 `att_update()` 调用与 `att` 命令，S1 已验证的链路完全不受影响。
- 配置宏 `ATT_ENABLE 0` 可整体关闭（`att_get()` 恒返回 `valid = 0`），命令仍可查询。
- 若 A-4/A-5 不达标且方案 B 也不成立，则登记 `18` 新条目并暂停 S4，先解决姿态质量。
