## 1. 背景

到 S3 结束，硬件链路已经“全通”：IMU 给 θ（`mid_att`，200 Hz）、力矩接口给 τ（`app_torque_set`，mN·m），
`torque` 命令已上板验证线性与饱和边界。缺的只有**中间那一段**：把 θ 变成 τ 的算法。

S4 只做“算得出来而且算得对”，不做“站得住”。站得住需要状态机、安全层、现场调参，
那是 S5/S6 的事。所以 S4 的产物是：

1. `alg_bal`（纯算法，无 HAL 依赖，可在 PC 上对拍）；
2. 一整套 **L1 仿真证据**（模型、增益、鲁棒性）；
3. 固件里的 **影子模式**（只算不执行，把 τ 打到 `prof`/日志里比对）。

## 4. 技术路线

### 4.1 模型（绕棱的一维倒立摆 + 反作用轮）

取棱为支点，轮轴与该棱平行。状态 `x = [φ, φ̇, ω]`：

```
I_tot · φ̈ = m·g·h·sinφ − τ + τ_f
J_w · (φ̈ + ω̇) = τ − τ_f
        ω̇ = (τ − τ_f)/J_w − φ̈
```

- `φ` 机体偏离平衡点的倾角 [rad]，`ω` 轮相对机体转速 [rad/s]
- `τ` 电机力矩 [N·m]，**正 = 给轮加速**，机体受到的反作用是 `−τ`
- `τ_f` 库仑摩擦 2.05 mN·m（S3 实测）

**符号要点（最容易写错的地方）**：机体力矩是 `−τ`，所以“正倾角”要靠“正指令”来刹车 →
控制律是 `u = +kp·φ + kd·φ̇ + kw·ω`，不是直觉上的负号。LQR 求出的 `K` 前面自带负号，
`u = −K·x` 在本约定下正好等于这个形式。

线性化（`sinφ ≈ φ`）：

```
A = [[0, 1, 0], [mgh/I_tot, 0, 0], [−mgh/I_tot, 0, 0]]
B = [[0], [−1/I_tot], [1/J_w + 1/I_tot]]
```

### 4.2 参数（全部有出处）

| 符号 | 值 | 单位 | 出处 |
|---|---|---|---|
| m | 0.459 | kg | 用户实测 301 g（不带电池）+ 158 g（电池） |
| h | 0.073 | m | 用户给定（质心到支点，先按 73 mm） |
| a | 0.104 | m | 用户给定（棱长 104 mm） |
| J_w | 5.12e-5 | kg·m² | **S3 台架实测**（轮 + 转子等效） |
| Kt | 0.02891 | N·m/A | `motor_cfg.h` 的 `MOTOR_KT_NM_A` |
| τ_max | 34.7 | mN·m | `Kt × 1.20 A`（电流量程上限） |
| τ_f | 2.05 | mN·m | S3 实测 |
| mgh | 0.3287 | N·m/rad | 由 m、g、h 计算 |
| I_solid | 3.310e-3 | kg·m² | 均质立方体 `(2/3)·m·a²` |
| I_hollow | 5.792e-3 | kg·m² | 薄壁立方体 `(7/6)·m·a²` |
| I_tot（设计用） | I_hollow | kg·m² | **保守取值**，真实值在两者之间 |

关于用户给的 `I₂ = 2.569e-5 kg·m²`：该值与“25.69 g·cm²”（= 2.569e-6 kg·m²）差 10 倍，
且与台架实测 5.12e-5 不符。**控制律只用实测值**，数据手册值仅作对照（见 `docs/18` T23）。

### 4.3 控制律

LQR（Bryson 权重 `Q = diag(1/0.05², 1/0.5², 1/50²)`、`R = 1/u0²`，`u0 = 2 mN·m`）：

| 增益 | 值 | 物理含义 |
|---|---|---|
| kp | 0.728 | mN·m/deg |
| kd | 0.0970 | mN·m/(deg/s) |
| kw | 4.0e-5 | mN·m/rpm（**正**，靠机体后仰刹轮） |

离散化：200 Hz（Ts = 5 ms，与 IMU 姿态率一致），前向欧拉即可（不稳定极点仅 7.5 rad/s，
Ts·λ = 0.038，离散误差可忽略）；实现上直接用连续增益。

`kw` 为正这件事必须记住：它意味着“轮转得越快，就给一点点正向力矩让机体微微后仰，
借重力把轮速降下来”。这是 LQR 的解，不是直觉能推的。

### 4.4 备选路线与被否理由

| 路线 | 描述 | 结论 |
|---|---|---|
| A: LQR 三状态（**采用**） | `u = kp·φ + kd·φ̇ + kw·ω` | 有物理意义、增益可复算、仿真鲁棒 |
| B: 串级 PID（角 PD 外环 + 轮速 PI 内环） | 直观、好调 | 内环积分会把常值力矩吃掉，且两级带宽接近易耦合，暂不用 |
| C: 极点配置 | 直接指定三个闭环极点 | 与 A 等价但缺“代价”解释，参数改动无依据 |

### 4.5 固件架构

```
USART1 IMU (200 Hz)  →  bsp_imu  →  mid_fdilink  →  mid_att (θ, θ̇)
                                                       │
                        mid_enc (ω, 1 kHz)  ───────────┤
                                                       ▼
                                          alg_bal_step()  200 Hz
                                                       │ τ [mN·m]
                                                       ▼
                                        app_balance 安全层（S5）
                                                       │
                                       app_torque_set() → mid_current → FOC 20 kHz
```

S4 阶段 `app_balance` 只做**影子**：算出 `τ_cmd` 存进状态结构，不调用 `app_torque_set`。

### 4.6 影子模式设计（S4 验收的核心手段）

- `bal on`：开始算，**不输出**；`bal off`：停止算。
- `bal`：打印 θ / θ̇ / ω / τ_cmd / 各项分力（`kp·φ`、`kd·φ̇`、`kw·ω`），便于看出哪一项在主导。
- `bal log <s>`：持续打印 200 Hz 采样，用户手扶立方体慢慢前后晃，我事后比对“τ_cmd 与 θ 的相位关系”。
  **相位正确性比幅值更重要**：若 τ_cmd 与 θ 同相且偏大，闭环会发散。

## 6. 验证方法

### 6.1 L1（已在 `sim/s4_design.py` 完成）

| 工况 | 结果 |
|---|---|
| 捕获范围 | 1/2/3/4/4.5° 均 RECOVER（0.34~0.6 s 回到 0.3° 内），峰值轮速 388~1489 rpm |
| 5°/6° 释放 | FALL（轮速冲到 ~1910 rpm，电压饱和后失力矩） |
| 惯量 ±50%（solid → hollow×1.5） | 全部 RECOVER |
| 传感器噪声 0.02/0.05/0.10° + 陀螺零偏 0.25 °/s | 全部 RECOVER |
| 环路延迟 0/5/10/20 ms | 全部 RECOVER（settle 4.38→5.01 s） |
| 初始轮速 300/600/900 rpm | 全部 RECOVER |

**长时限特征**：1 s 内 φ 就压到 0.3° 以内，剩余的是**轮速慢模**（约 4 s 量级），
残余轮速约 ±590 rpm，1 s 后 |τ| ≤ 4 mN·m。这说明 S4 的增益够用，但“轮速不会自己回中”，
需要 S6 的偏置积分（`docs/18` T20）。

### 6.2 L2（主机测试）

- `alg_bal` 单步与 python 逐位比对（A-4）；
- 姿态无效（`valid=0`）时输出必须为 0；
- 限幅：|τ| ≤ 34 mN·m；
- 影子模式不得调用 `app_torque_set`（用 fake 打桩计数验证）。

### 6.3 L3（上板，需请示）

## 8. 回退

- 影子模式不驱动电机，出错最多是打印错，**回退成本为零**：`bal off` 即可。
- 若相位判据不通过：先查 `ATT_SIGN` 与 `mid_att` 的轴配置，再查 `alg_bal` 的符号；
  两者的区别可由“手扶静止时 τ_cmd 的符号”区分。
