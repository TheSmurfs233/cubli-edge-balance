## 1. 背景

到 S3 结束，硬件链路已经“全通”：IMU 给 θ（`mid_att`，200 Hz）、力矩接口给 τ（`app_torque_set`，mN·m），
`torque` 命令已上板验证线性与饱和边界。缺的只有**中间那一段**：把 θ 变成 τ 的算法。

S4 只做“算得出来而且算得对”，不做“站得住”。站得住需要状态机、安全层、现场调参，
那是 S5/S6 的事。所以 S4 的产物是：

1. `alg_bal`（纯算法，无 HAL 依赖，可在 PC 上对拍）；
2. 一整套 **L1 仿真证据**（模型、增益、鲁棒性）；
3. 固件里的 **影子模式**（只算不执行，把 τ 打到 `prof`/日志里比对）。

## 4. 技术路线

### 4.1 模型（绕棱的一维倒立摆 + 反作用轮）

取棱为支点，轮轴与该棱平行。状态 `x = [φ, φ̇, ω]`：

```
I_tot · φ̈ = m·g·h·sinφ − τ + τ_f
J_w · (φ̈ + ω̇) = τ − τ_f
        ω̇ = (τ − τ_f)/J_w − φ̈
```

- `φ` 机体偏离平衡点的倾角 [rad]，`ω` 轮相对机体转速 [rad/s]
- `τ` 电机力矩 [N·m]，**正 = 给轮加速**，机体受到的反作用是 `−τ`
- `τ_f` 库仑摩擦 2.05 mN·m（S3 实测）

**符号要点（最容易写错的地方）**：机体力矩是 `−τ`，所以“正倾角”要靠“正指令”来刹车 →
控制律是 `u = +kp·φ + kd·φ̇ + kw·ω`，不是直觉上的负号。LQR 求出的 `K` 前面自带负号，
`u = −K·x` 在本约定下正好等于这个形式。

线性化（`sinφ ≈ φ`）：

```
A = [[0, 1, 0], [mgh/I_tot, 0, 0], [−mgh/I_tot, 0, 0]]
B = [[0], [−1/I_tot], [1/J_w + 1/I_tot]]
```

### 4.2 参数（全部有出处）

| 符号 | 值 | 单位 | 出处 |
|---|---|---|---|
| m | 0.459 | kg | 用户实测 301 g（不带电池）+ 158 g（电池） |
| h | 0.073 | m | 用户给定（质心到支点，先按 73 mm） |
| a | 0.104 | m | 用户给定（棱长 104 mm） |
| J_w | 5.12e-5 | kg·m² | **S3 台架实测**（轮 + 转子等效） |
| Kt | 0.02891 | N·m/A | `motor_cfg.h` 的 `MOTOR_KT_NM_A` |
| τ_max | 34.7 | mN·m | `Kt × 1.20 A`（电流量程上限） |
| τ_f | 2.05 | mN·m | S3 实测 |
| mgh | 0.3287 | N·m/rad | 由 m、g、h 计算 |
| I_solid | 3.310e-3 | kg·m² | 均质立方体 `(2/3)·m·a²` |
| I_hollow | 5.792e-3 | kg·m² | 薄壁立方体 `(7/6)·m·a²` |
| I_tot（设计用） | I_hollow | kg·m² | **保守取值**，真实值在两者之间 |

关于用户给的 `I₂ = 2.569e-5 kg·m²`：该值与“25.69 g·cm²”（= 2.569e-6 kg·m²）差 10 倍，
且与台架实测 5.12e-5 不符。**控制律只用实测值**，数据手册值仅作对照（见 `docs/18` T23）。

### 4.3 控制律与增益

LQR（Bryson 权重 `Q = diag(1/0.05², 1/0.5², 1/50²)`、`R = 1/u0²`，`u0 = 2 mN·m`）。

**单位约定（关键）**：控制律在固件里按**弧度**计算，增益的原始单位是「N·m / 状态单位」：

```
u[N·m] = kp·φ[rad] + kd·φ̇[rad/s] + kw·ω[rad/s]
```

下表同时给出工程单位（按度 / rpm 显示，便于调试对照）：

| 增益 | 原始值（固件单位） | 工程单位（表示用） | 物理含义 |
|---|---|---|---|
| kp | 0.728 N·m/rad | **12.7 mN·m/deg** | 刚度：比重力刚度 5.74 mN·m/deg 硬 2.2 倍 |
| kd | 0.0970 N·m/(rad/s) | **1.69 mN·m/(deg/s)** | 阻尼 |
| kw | 4.0e-5 N·m/(rad/s) | **0.00419 mN·m/rpm** | 轮速回中（**正**，靠机体后仰借重力刹轮） |

换算：`1 deg = 0.017453 rad`、`1 rpm = 0.10472 rad/s`。

**固件实现只能写原始值**（乘弧度后的状态）。若把工程单位直接写进代码，kp 会差 17.5 倍、
kw 会差 100 倍——这类“数值对、单位错”的错误编译器抓不到，只能靠本节与 `bal` 命令的分项打印对照。

两条自校验数字：

- 指令饱和角：`τ_max/kp = 34.7e-3 / 0.728 = 0.0477 rad = 2.73°`
- 590 rpm 残速时轮速项力矩：`4.0e-5 × 61.8 = 2.5 mN·m`

离散化：200 Hz（Ts = 5 ms，与 IMU 姿态率一致），前向欧拉即可（不稳定极点仅 7.5 rad/s，
Ts·λ = 0.038，离散误差可忽略）；实现上直接用连续增益。

`kw` 为正这件事必须记住：它意味着“轮转得越快，就给一点点正向力矩让机体微微后仰，
借重力把轮速降下来”。这是 LQR 的解，不是直觉能推的。

### 4.4 备选路线与被否理由

| 路线 | 描述 | 结论 |
|---|---|---|
| A: LQR 三状态（**采用**） | `u = kp·φ + kd·φ̇ + kw·ω` | 有物理意义、增益可复算、仿真鲁棒 |
| B: 串级 PID（角 PD 外环 + 轮速 PI 内环） | 直观、好调 | 内环积分会把常值力矩吃掉，且两级带宽接近易耦合，暂不用 |
| C: 极点配置 | 直接指定三个闭环极点 | 与 A 等价但缺“代价”解释，参数改动无依据 |

### 4.5 固件架构

```
USART1 IMU (200 Hz)  →  bsp_imu  →  mid_fdilink  →  mid_att (θ, θ̇)
                                                       │
                        mid_enc (ω, 1 kHz)  ───────────┤
                                                       ▼
                                          alg_bal_step()  200 Hz
                                                       │ τ [mN·m]
                                                       ▼
                                        app_balance 安全层（S5）
                                                       │
                                       app_torque_set() → mid_current → FOC 20 kHz
```

S4 阶段 `app_balance` 只做**影子**：算出 `τ_cmd` 存进状态结构，不调用 `app_torque_set`。

### 4.6 影子模式设计（S4 验收的核心手段）

- `bal on`：开始算，**不输出**；`bal off`：停止算。
- `bal`：打印 θ / θ̇ / ω / τ_cmd / 各项分力（`kp·φ`、`kd·φ̇`、`kw·ω`），便于看出哪一项在主导。
- `bal log <s>`：持续打印 20 ms 一行（1..30 s），用户手扶立方体慢慢前后晃，我事后比对“τ_cmd 与 θ 的相位关系”。
  **相位正确性比幅值更重要**：若 τ_cmd 与 θ 同相且偏大，闭环会发散。

实现要点（S4 步骤 5）：

| 位置 | 作用 |
|---|---|
| `User/Cfg/board_cfg.h` 7d 节 | `BAL_KP_NM_RAD` / `BAL_KD_NM_RPS` / `BAL_KW_NM_RPS` / `BAL_SIGN` / `BAL_MAX_MNM 33.0` |
| `User/Alg/alg_bal.c/h` | 纯数学：`sign` 一次生效，`ALG_BAL_TAU_MIN_MNM 1.0` 死区，`max_nm` 限幅 |
| `app_bal_update()` | 单位换算（deg→rad、rpm→rad/s）后调 `alg_bal_step()`，只保存结果 |
| `app_bal_set()` | `on` 需 `alg_bal_ready()` 且 `att_get()->valid`；`off` 清零 |
| `bal`、`bal on/off/log` | 命令台接口（`app_cmd.c`） |

**影子模式为什么必须真影子**：`app_bal_update()` 全程**不调用 `app_torque_set()`**，
L2 用两条断言盯住它——`app_torque_get() == 0`、`app_foc_info()->iq_ref == 0`。
若哪天真接了控制输出，这两条会立刻红，避免“以为在影子模式、其实已经在推轮子”。

`BAL_MAX_MNM` 取 33.0 而非 34.0：让平衡律自己的限幅先于 `app_torque_set()` 的上限拒绝，
这样 `bal` 打印的 `SATURATED` 一定来自控制律，而不是力矩接口的二次裁剪。

### 4.7 S6 增量预研：给 ω 加积分（`docs/18` T20）

S4 采用三状态、**不含积分**。其稳态轮速由「轮速项必须顶住库仑摩擦」决定：

```
ω_ss = τ_f / kw = 2.05e-3 / 4.0e-5 ≈ 51 rad/s ≈ 490 rpm
```

这只在纯库仑摩擦模型里是确定值。真实轴承有静摩擦，轮子可以在 `|ω| ≤ 490 rpm` 的任意一点被
“锁住”而不滑动，所以实测稳态轮速取决于历史、不保证回零。**没有对 ω 的回复力，是 S4 的已知短板。**

预研结论（已在 `sim/` 同款模型上验证，供 S6 直接用，不必重算）：把 wheel-speed 误差积分成第 4 个状态
（`ż = ω`）再解 LQR：

| 增益 | 值 | 工程单位 |
|---|---|---|
| kp | 0.750 N·m/rad | 13.1 mN·m/deg |
| kd | 0.0999 N·m/(rad/s) | 1.74 mN·m/(deg/s) |
| kw | 5.40e-5 N·m/(rad/s) | 0.00516 mN·m/rpm |
| ki | 1.00e-5 N·m/(rad·s) | — |

- 闭环极点：`−7.52, −7.52, −0.728, −0.266`（新增慢模 τ ≈ 3.8 s）
- **但加入静摩擦模型后复算，结论要打折**：轮速确实能被拉到 0 附近，代价是出现一个长周期极限环
  （60 s 窗口内实测：φ 摆动约 ±0.46°，轮速摆动约 ±600 rpm，周期 ~20 s）。原因很直接：
  轮子一旦被静摩擦“锁住”，电机力矩不再传到机体，机体就成了一个没有控制量的倒立摆，
  稍微歪一点就必须重新“解列”，一解列就是一次力矩冲击，积分器于是反复过冲。
- 对比：同一模型下三状态版本姿态更稳（φ 长期 < 0.01°），只是轮速停在 ~390 rpm 不回零。

**按 S4 三状态实测值复算的稳态轮速**：`sim/s4_design.py` 现在给出 388 rpm 而不是 490 rpm，
差值是**陀螺零偏 0.25 °/s 经 `kd` 贡献的常值力矩** `kd·0.00436 = 0.42 mN·m` 抵掉了一部分摩擦。
说明“稳态轮速”由摩擦与零偏共同决定，不是一个可以写死的常数。

**风险（S6 必须处理）**：积分饱和、静摩擦死区导致的长周期极限环。可选路线三条：
① 积分器 + 抗饱和 + 微幅 dither（让轮子始终处于“将锁未锁”状态，保住控制权限）；
② 用扰动观测器/偏置估计（Cubli 文献里的 bias estimator）替代纯积分；
③ 接受一个小的常值轮速，不做 ω 回零。
S6 阶段必须先用 L1 把三条路线比完再上板。

**历史教训**：早先试过把积分量当“倾角零点修正”（`u = kp(φ − trim) + …`），扫遍特征值都找不到稳定组合
——正 trim 要求正稳态力矩，而正力矩会让轮子越转越快，属结构性符号错误。积分量必须直接进力矩通道。

**步骤 3 的四个设计决定**（都在代码注释里写明理由）：

1. **符号只在一处**：`cfg.sign` 乘在求和之后，控制律本身永远用正值增益。物理方向未定（`18#T19`）时只改一个数。
2. **死区在限幅之前**：`|τ| < 1 mN·m` 先归零，再判饱和。0 永远在限幅内，所以两者不会互相干扰。
3. **原始值单独留**：`tau_raw_nm` 保存限幅前的结果，`bal` 命令能看出“是增益给大了，还是被限幅卡住了”。
4. **拒绝非法调参**：`max_nm <= 0`、增益为负、`sign` 不是 ±1 一律拒绝并把 `alg_bal_ready()` 置 0，
   避免用半套参数算出“看起来正常”的力矩。NaN 靠比较运算天然失败来挡（不需要 `math.h`）。

**长时限特征**：稳态时 φ 收敛到 0.01° 以内，**轮速停在约 388 rpm 不再变化**，稳态力矩 2.05 mN·m
（正好等于库仑摩擦，这就是它必须一直转的原因）。注意 490 rpm 是「只有摩擦」时的解析值，

结论：S4 的增益够用，“倾角能稳住、力矩不饱和”，但**“轮速不会自己回中”**。S4 的验收判据因此写成
“倾角稳住 + 轮速不持续单向爬升”，而不是“轮速回 0”；轮速回零是 S6 的 `18#T20`（见 §4.7）。
