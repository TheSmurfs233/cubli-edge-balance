## 维护约定

| 约定 | 说明 |
|---|---|
| 改代码必须同一次提交更新文档 | 接口/参数变了改对应框架文档，行为变了加 `00_开发日志` 条目 |
| 开发日志只增不改 | 新条目追加在文件末尾，编号连续（`00_开发日志.md`） |
| "待定"只能写在 18 | 其它文档禁止出现未决数值，只能引用 `18#T<n>` |
| 数字必须带单位、必须与代码宏一致 | 改宏必须全仓库 grep 旧值 |
| 表格列数必须一致 | 由 `test/doc_check.py` 自动校验（S1 建） |
| 源码 `.c/.h` 必须纯 ASCII | ARMCC V5 按 GBK 解析，中文串会报 `#8: missing closing quote` |
