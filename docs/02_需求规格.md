# 需求规格（G1 门禁）

> 版本：v0.2 · 日期：2026-11-03 · 状态：**已评审（G1 通过，阈值待 S4 锁定）**
> 对应流程：`workflow/01_开发流程总纲.md` 阶段 A / 门禁 G1
> 门禁要求：**目标可验证 + 硬件约束写清 + 明确不做什么**，三者缺一不许进阶段 B。

---

## 1. 一句话目标

在一块 STM32G431 驱动板上，用**单台无刷电机 + 动量轮**，让立方体绕**一条棱**保持倒立平衡
（一维边平衡），并在小幅扰动后自行恢复。

---

## 2. 可验证目标

> 数值型阈值目前是"建议值"，需在方案阶段用 L1 仿真标定后锁定；
> 标定结果回填本表并把状态改为"已锁定"。

| # | 目标 | 验收标准（可量化） | 测法 | 阈值状态 |
|---|---|---|---|---|
| G-1 | 姿态数据可信 | 静止水平放置 30 s，俯仰角漂移 ≤ 0.5° | 串口打印姿态角，与水平仪比对 | 建议值 |
| G-2 | 轮速闭环 | 指令轮速 0~3000 rpm 双向跟随，稳态误差 ≤ 2% | `wave` 波形记录 | 建议值 |
| G-3 | 一维边平衡成立 | 从 ±3° 内释放，连续保持 ≥ 60 s 不倒 | 实测计时，3 次中 2 次成功 | 建议值 |
| G-4 | 抗小扰动 | 侧向轻推后 2 s 内恢复平衡 | 实测，冲量阈值方案阶段标定 | 建议值 |
| G-5 | 安全兜底 | 倾角 > 25° 立即停轮封波，不失控 | 手动倾倒 5 次，每次正确 | 建议值 |
| G-6 | 可观测 | 串口能实时输出姿态角/轮速/电流/控制量，≥ 200 帧/s 不丢帧 | 波形工具抓取统计 | 建议值 |

---

## 3. 非目标（本版明确不做）

| # | 不做的事 | 原因 |
|---|---|---|
| N-1 | 点平衡（三维角平衡） | 需要 3 个动量轮，硬件形态不同 |
| N-2 | jump-up（跳出/跳起） | 需要主动刹车与冲击控制，难度最高 |
| N-3 | 三电机协同 / CAN 多板通信 | 本版只有一块驱动板 |
| N-4 | 无线调参（WiFi/蓝牙） | 不引入额外通信栈，串口够用 |
| N-5 | 无感 FOC | 动量轮有 MT6701，有感更稳 |
| N-6 | 电池充放电管理 | 本版用台架电源或现成电池包，不自研 BMS |

> 非目标是**本版**的边界，不是永久结论；要做需先改本文并重新过 G1。

## 4. 硬件约束（已确认事实）

> 详细引脚与量程见 [19_硬件资源与引脚映射.md](19_硬件资源与引脚映射.md)；
> 未定项见 [18_待确认清单.md](18_待确认清单.md)。

| 约束 | 现状 |
|---|---|
| 主控 | **STM32G431KBT6**（LQFP32，128 KB Flash / 32 KB RAM），单板单电机，板型沿用 dsh_foc |
| 电流环 | 20 kHz，TIM1 中心对齐 + ADC 注入组（JEOC 中断） |
| 电流量程 | **±1.32 A**（25 mΩ × 50 V/V，1.65 V 偏置）——超过即饱和 |
| 母线 | 12 V 标称；可测 0~23.1 V；欠压 9.0 V / 过压 13.8 V 阈值 |
| 轮角度 | MT6701，SPI1（SSI），分辨率与零位见 19 |
| 动量轮电机 | 用户提供的 12 V 云台级无刷电机：**7 极对、KV 330 rpm/V**、相电阻 **2.3 Ω**、相电感 **≈0.5 mH**；`Kt = 9.549/330 = 0.0289 N·m/A`（参数取自 dsh_foc 已验收的实测标定，见 18#T3） |
| 最大反作用力矩 | `Kt × I_MAX = 0.0289 × 1.2 = **34.7 mN·m**`（受电流量程限制，这是整机最硬的物理约束） |
| 姿态 | WHEELTEC N100 Mini，USART1 @921600，**实测 200 帧/s（5 ms/帧）** |
| 调试口 | **USART2（PA2/PA3）+ 板载 CH340N → USB Type-C**，1 Mbaud |
| 硬件过流保护 | **无**（BKIN 引脚已被占用），只有软件保护 |
| 资源 | 合并估算 75~85 KB Flash / ~23 KB RAM，128 KB 可容纳；裁剪边界见 [90_已知问题与限制.md](90_已知问题与限制.md) H-6 |

## 5. 时间指标（由硬件反推，方案阶段确认）

| 回路 | 频率 | 来源 | 说明 |
|---|---|---|---|
| 电流环 | 20 kHz | 沿用 dsh_foc | 50 µs 周期，已实测 ISR 2.4 µs |
| 轮速度环 | 1 kHz | 沿用 dsh_foc（ADC ISR 内 20 分频） | 实测与电流环严格同步 |
| 姿态/平衡环 | **200 Hz** | 受 IMU 帧率限制 | 5 ms 一拍，是否够用需仿真评估 |
| 命令/日志 | 主循环 | 沿用 dsh_foc | 非实时 |
