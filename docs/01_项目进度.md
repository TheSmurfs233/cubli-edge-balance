| 2026-11-03 | 平衡环输出**力矩指令**，由 20 kHz 电流环零阶保持 | 机械时间常数远大于电气时间常数；避免让平衡律直接决定占空比 | 需要 S3 先做力矩标定 |
| 2026-11-03 | L1 仿真跑在 **Windows 的 uv 虚拟环境**（numpy/scipy/control） | WSL 无 numpy 且 pypi 不通（附录 A） | 仿真脚本保持 POSIX 写法，将来可原样搬回 WSL |
| 2026-11-03 | 芯片确认为 **G431KBT6（128 KB Flash / 32 KB RAM）** | 用户核对实物 | 不需要为省 Flash 提前裁无感（`18#T1`） |
| 2026-11-03 | **USART1 → IMU（921600）**，**USART2 → 调试台（1 Mbaud，板载 CH340N）** | 姿态数据是平衡的必需品，调试口可换 | `18#T2` 闭环 |

| 2026-11-03 | 串口 DMA 优先级全部 `LOW`，只保留编码器 `SPI1_RX` 为 `VERY_HIGH` | MT6701 每 50 µs 要一次角度，电流环等不起仲裁 | `00` #005 |
| 2026-11-03 | **CubeMX 工程由用户在 GUI 生成** | `myfoc.uvprojx` 被手改 12 次，完整重生成会丢失 | 规格固化在 [41](41_CubeMX配置规格.md) |

| 2026-11-03 | fake HAL 的 UART 改成**按句柄分派的多实例** | 双串口工程里写死 `&huart1` 会把 IMU 的完成回调算到调试口 | 新增 `fake_imu_*` 一族 |
